# On-Device Handwritten OCR & Vector Store System (Version 1.0.0)

A 100% offline, privacy-first Android application developed in native **Kotlin** and **Jetpack Compose**. The system performs high-accuracy handwritten/printed text extraction from PDFs, images, and camera scans using **PaddleOCR** as the primary OCR engine, semantic chunking, dense vector embedding generation, and persistent vector database indexing using **ObjectBox DB**.

## 📦 App Size Breakdown (~227 MB Installed / 117 MB APK)

The application size (~117 MB compressed APK / ~227 MB extracted on-device) is due to **100% offline, self-contained AI models and C++ native engines**. Below is the exact breakdown:

### 1. Bundled Native C++ JNI Binaries (`lib/`) — ~110 MB (Multi-ABI Fat Build)
Because `app-debug.apk` is a universal developer APK, it includes native compiled C++ shared libraries for **4 CPU Architectures** (`arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`):
- **ONNX Runtime Native Engine (`libonnxruntime.so`)**: ~64 MB (16.2 MB per ABI) — Executes PaddleOCR ONNX neural network models on device CPU/NPU.
- **MediaPipe GenAI & Embedding Engine (`libllm_inference_engine_jni.so` & `libmediapipe_tasks_text_jni.so`)**: ~40 MB — On-device 384-dim dense vector embedding generator.
- **ObjectBox Native Vector Database Engine (`libobjectbox-jni.so`)**: ~8 MB — C++ HNSW vector index engine.
- **OpenCV Image Processing Utility (`libimage_processing_util_jni.so`)**: ~12 MB — Contrast binarization & image manipulation.

### 2. Bundled PaddleOCR Neural Models (`assets/paddle_ocr/models/`) — ~55 MB
Pre-bundled offline OCR neural network model weights so text extraction works without requiring network downloads on first launch:
- `ch_PP-OCRv4_rec_infer` & `en_PP-OCRv4_rec_infer` (Chinese & English recognition weights): ~18.3 MB
- `ch_PP-OCRv4_det_infer` (DBNet text line detection weights): ~4.7 MB
- `korean_PP-OCRv4_rec_infer` & `japan_PP-OCRv4_rec_infer`: ~33.5 MB

### 3. Multi-DEX Bytecode (`classes.dex` – `classes11.dex`) — ~60 MB
Compiled Java/Kotlin bytecode for Jetpack Compose, Material 3, CameraX, MediaPipe, and ObjectBox frameworks.

## ⚡ How to Reduce App Size to ~65 MB (Production Release)

By default, developer debug APKs contain binaries for all 4 CPU architectures. For production release, building an **Android App Bundle (.aab)** or restricting ABI splits targets only your specific phone architecture (`arm64-v8a`), which **cuts the app size by ~70% down to ~65-75 MB**:

```kotlin
// app/build.gradle.kts
android {
    splits {
        abi {
            isEnable = true
            reset()
            include("arm64-v8a") // Keeps only modern 64-bit ARM phone architecture
            isUniversalApk = false
        }
    }
}
```

## 🧠 Primary Model Used for Extraction & Inference

### 1. Primary OCR Model: PaddleOCR (PP-OCRv4 / PP-OCRv6)
- **Model Framework**: PaddleOCR ONNX Models (`ch_PP-OCRv4_det_infer.onnx` and `ch_PP-OCRv4_rec_infer.onnx`) with `ppocr_keys_v1.txt` character dictionary.
- **Target**: High-accuracy text line detection (DBNet) and sequence recognition for handwritten and printed text.
- **Execution**: On-device native execution via Microsoft ONNX Runtime (`ai.onnxruntime.OrtSession`) with NCHW float32 tensor normalization `[1, 3, 48, 320]` and CTC Greedy Decoding.

### 2. Dense Vector Embedding Model: Google MediaPipe Universal Sentence Encoder
- **Embedding Dimensions**: `384` dense float vector values per text chunk.
- **Indexing**: ObjectBox HNSW Index (`@HnswIndex(dimensions = 384)`).
